# Universe PDF

Русскоязычный Telegram-бот на Python: фотографии, PDF, текст и офисные документы
собираются в один PDF в порядке отправки. Поддерживаются альбомы и многостраничные
TIFF/GIF, автоматический поворот фото и кириллица.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Начать работу, показать инструкцию |
| `/help` | Полное описание и ограничения |
| `/newpdf` | Очистить очередь и начать новый PDF |
| `/compile` | Завершить добавление и отправить общий PDF |
| `/cancel` | Отменить операцию и удалить файлы |

Есть русские кнопки «Новый PDF», «Собрать PDF», «Отмена», «Помощь».
Команды записаны латиницей из-за требований Telegram; весь интерфейс русский.
Бот работает в личных чатах. Первый файл автоматически создаёт очередь.
Перед `/compile` дождитесь подтверждения приёма всех файлов, особенно альбома.

## Быстрый запуск с Docker

```sh
git clone https://github.com/Lonely-godd/Universe-PDF.git
cd Universe-PDF
cp .env.example .env
# Заполните BOT_TOKEN в .env
docker compose up -d --build
docker compose logs -f
```

PowerShell: вместо `cp` можно использовать `Copy-Item .env.example .env`.
В образ уже входят LibreOffice и шрифты. Постоянно работающий бот требует
включённого сервера/компьютера. Публикация исходников на GitHub сама бота не запускает.
Остановка: `docker compose down`. Не запускайте два экземпляра с одним токеном.

## Локальный запуск (Python 3.12+)

```sh
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.lock
python -m pip install -e .
cp .env.example .env
# Заполните .env
python -m universe_pdf.bot
```

Для Word/Excel/PowerPoint и OpenDocument установите LibreOffice, затем укажите
`OFFICE_BINARY` в `.env`, если `soffice` отсутствует в PATH. Пример для Windows:
`OFFICE_BINARY=C:/Program Files/LibreOffice/program/soffice.exe`.
Без LibreOffice изображения, PDF и текст работают, а офисные файлы возвращают
понятное сообщение. Для текста нужен TrueType-шрифт с кириллицей; автоматически
ищутся DejaVu Sans на Linux и Arial на Windows/macOS. Можно задать `FONT_PATH`.

## Форматы и ограничения

- Фото: JPG/JPEG, PNG, WEBP, BMP, TIFF/TIF, GIF, HEIC/HEIF. Все кадры TIFF/GIF
  включаются в PDF. Фото вписываются в A4, фон прозрачности белый. Для передачи
  оригинала отправляйте фотографию как файл: Telegram сжимает обычные фото.
- PDF: страницы сохраняют размер. Пароли не поддерживаются; интерактивные поля,
  аннотации и действия не переносятся. Подписи исходных PDF не сохраняют юридическую
  проверяемость после пересборки. Для видимых заполненных полей сначала экспортируйте
  плоский PDF в исходной программе.
- TXT/CSV/MD: обычный текст, без интерпретации Markdown/таблиц; UTF-8, UTF-16 с BOM,
  Windows-1251. Другие кодировки нужно предварительно преобразовать в UTF-8.
- DOC/DOCX, ODT, RTF, XLS/XLSX, ODS, PPT/PPTX, ODP: LibreOffice. Разбиение таблиц
  на страницы зависит от исходных настроек печати; внешний вид — от шрифтов сервера.
- Архивы, HTML, SVG, видео и неизвестные форматы отклоняются.

По умолчанию: 100 файлов по 20 МБ, очередь до 100 МБ, 500 страниц, результат до
49 МБ, 20 активных очередей, 1 конвертация одновременно. Размеры в десятичных МБ.
Таймаут одной сборки 180 секунд, офисного файла 60 секунд. Параметры есть в
`.env.example`. Облачный [Telegram Bot API](https://core.telegram.org/bots/api#getfile)
ограничивает скачивание файла до 20 МБ, [отправку документа](https://core.telegram.org/bots/api#senddocument)
— до 50 МБ; для результата оставлен запас.

## Хранение и доступ

Токен хранится в `.env`/окружении. `.env` исключён из Git и Docker context.
`ALLOWED_USER_IDS=123456789,987654321` ограничивает доступ; пустое значение разрешает
всем. Логи содержат типы ошибок, без содержимого файлов и URL с токеном.

Документы лежат во временных папках с серверными именами. Очереди пользователей
разделены. После успешной отправки, отмены или часа неактивности файлы удаляются
(проверка TTL раз в минуту). При ошибке очередь сохраняется для повторного `/compile`.
После отмены во время сборки нужно дождаться сообщения об очистке. Начавшуюся
отправку в Telegram отменить нельзя. Если Telegram принял PDF, но ответ потерялся,
повторная попытка может прислать второй экземпляр.

Очереди не восстанавливаются после перезапуска. Штатное завершение удаляет папку
запуска; при аварийном завершении локального процесса временная папка может остаться
в системном TEMP. В Docker используется временный tmpfs. Рабочие процессы не
получают токен, LibreOffice запускается с отдельным профилем и запрещёнными макросами.
Docker запускается без root, с read-only root и лимитами CPU/памяти. Конвертация
недоверенных офисных документов требует обновлений LibreOffice. Для публичной
высоконагруженной установки вынесите конвертер в отдельную среду без сетевого доступа.

## Разработка и проверки

```sh
python -m pip install -e '.[dev]'
pytest -q
ruff check .
ruff format --check .
```

Спецификация и исходные приёмочные тесты находятся в первом коммите, реализация
добавлена после первого запуска тестов. [SPEC.md](SPEC.md) описывает поведение и
критерии приёмки. В GitHub Actions установлены LibreOffice и шрифты, тесты запускаются
на Python 3.12 и 3.13. Локально офисная интеграция пропускается при отсутствии LibreOffice.
`requirements.lock` фиксирует runtime-зависимости; dev-инструменты заданы в `pyproject.toml`.
