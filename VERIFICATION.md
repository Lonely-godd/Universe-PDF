# Проверка реализации

Проверено 19 октября 2026 года.

- До реализации добавлены спецификация и тесты; первый запуск завершился ошибками
  импорта отсутствующих модулей (ожидаемая начальная фаза).
- Windows, Python 3.12 и 3.13: на каждой версии **87 тестов пройдено, без пропусков**.
  Для интеграционных тестов отдельно распакован LibreOffice 26.2.6 из официального
  установщика с действительной подписью The Document Foundation; системная установка
  не выполнялась. Проверена настоящая конвертация DOCX, XLSX и PPTX.
- Через отдельный рабочий процесс собран смешанный PDF: фотография + таблица Excel +
  исходный PDF + русский текст. Проверены четыре страницы, их порядок и содержимое.
- Проверены JPG, PNG, WEBP, BMP, TIFF, GIF, HEIC, смешанный PDF, порядок страниц,
  кириллица, кодировки, переносы, прозрачность, EXIF и многостраничные изображения.
- Проверены ошибочные/зашифрованные документы, размеры, лимит страниц, изоляция
  пользователей, TTL, отмена, повторная отправка и очистка после неудачной загрузки.
- Для меню PDF проверены реальные операции через worker: извлечение по номерам
  с 1, порядок и содержимое страниц, удаление, ZIP с частями, выбор последнего PDF,
  ошибки ввода и отправки, повторные операции, отмена при проверке и обработке.
  Исходники и другие файлы очереди сохраняются. Общая сборка после выборки страниц
  по-прежнему включает исходный PDF целиком.
- Отдельный рабочий процесс создаёт PDF; тест таймаута проверяет завершение процесса
  и отсутствие BOT_TOKEN и посторонних секретов в передаваемом окружении.
- `ruff check .`, `ruff format --check .`, `pip check` проходят.
- Установка из `requirements.lock` проверена в чистом окружении Python 3.13.
  Явно задана UTF-8, чтобы комментарии читались pip при любой системной кодировке Windows.
- `docker compose config --quiet` проходит. Локальная сборка образа не выполнялась:
  Docker Engine на машине не запущен.
- Тестовый PDF с фото и русским текстом отрендерен в изображения и просмотрен:
  нет обрезки фото, пропавшей кириллицы или выхода текста за поля.
- Telegram `getMe` успешно вернул `@universe_pdf_bot`, активного webhook нет.
  Русские описания slash-команд и бота установлены через Bot API. Проверены запуск
  Application, планировщика очистки и корректная остановка без long polling.
- История Git проверена на наличие настоящего токена; `.env` не отслеживается.
- Реальная отправка файла пользователем через Telegram в этой проверке не выполнялась.

GitHub Actions запускает тесты на Python 3.12/3.13 с установленным LibreOffice,
включая офисные интеграционные тесты. Актуальный результат смотрите во вкладке
[Actions](https://github.com/Lonely-godd/Universe-PDF/actions).
