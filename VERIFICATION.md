  по-прежнему включает исходный PDF целиком.
- Отдельный рабочий процесс создаёт PDF; тест таймаута проверяет завершение процесса
  и отсутствие BOT_TOKEN и посторонних секретов в передаваемом окружении.
- `ruff check .`, `ruff format --check .`, `pip check` проходят.
- Установка из `requirements.lock` проверена в чистом окружении Python 3.13.
  Явно задана UTF-8, чтобы комментарии читались pip при любой системной кодировке Windows.

- Тестовый PDF с фото и русским текстом отрендерен в изображения и просмотрен:

## Исправление таймаутов скачивания

После сообщений пользователя о JPG/PDF проверены логи и метрики Railway:
сервис оставался Online, пиковая память около 49 МБ при лимите 500 МБ,
в логах — `TimedOut` на загрузке. В коде использовались стандартные таймауты
python-telegram-bot 22.8: чтение и соединение по 5 секунд, без повторов.
Исходные логи не различали `get_file` и скачивание тела, поэтому точный
сетевой этап прошлых сбоев по ним установить нельзя.

Добавлены увеличенные таймауты, до трёх попыток для временных сетевых ошибок,
общий предел 120 секунд, очистка незавершённой загрузки и безопасная диагностика.
Регрессионные тесты написаны до реализации. **97 тестов прошли на Python 3.12**,
включая LibreOffice. `ruff check .` и `ruff format --check .` проходят.
Тест с настоящим локальным HTTP-сервером воспроизводит медленную передачу:
короткий таймаут клиента приводит к `TimedOut`, новые параметры позволяют получить
полный файл. Проверены оба этапа сетевых ошибок, исчерпание попыток, общий дедлайн,
отмена, неповторяемая ошибка и отсутствие приватных данных в логах.
Повторную загрузку конкретных проблемных файлов пользователя после обновления
нужно проверить отдельно; тест не доказывает отсутствие сетевых проблем Railway/Telegram.

В runtime-логах в 16:37 UTC зарегистрировано `Application started`, ошибок запуска нет.
Идентификатор проверенного деплоя: `ef73f6f7-98da-4a2a-924c-03ed113b0bd6`.

Источник сервиса — GitHub `Lonely-godd/Universe-PDF`, `main`, автоматические деплои
включены. Токен задан через Railway Variables. Параметры и ограничения текущего

Linux-образа и запуска приложения; она не заменяет отправку настоящих файлов
через Telegram пользователем.

GitHub Actions запускает тесты на Python 3.12/3.13 с установленным LibreOffice,
